# Backend Module (`src/backend/`)

This directory will contain the Node.js / Express backend services for SupplyGuard AI.

## Planned Scope
- Node.js and Express REST API web server.
- Database connection layer (MongoDB).
- Rerouting and fleet optimization logic integration.
- Cold-chain IoT sensor log ingestion and excursion severity evaluation.
- IBM Bob decision engine integration endpoints.

*Implementation will be finalized in Phase 2.*
