# Frontend Module (`src/frontend/`)

This directory will contain the React frontend application for SupplyGuard AI.

## Planned Scope
- Built with React and Vite.
- UI/dashboard components for monitoring active shipments and disruptions.
- Real-time fleet utilization and cold-chain excursion alerts.
- IBM Bob conversational AI decision-support interface.
- Consumes backend REST APIs.

*Implementation will be finalized in Phase 2.*
