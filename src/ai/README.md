# AI Module Directory (`src/ai/`) — Module C (Member 3)

This directory hosts the AI decision-support logic, recommendation synthesis engines, prompt templates, and IBM Bob conversational services.

---

## Folder Organization

- **`services/`**: Recommendation synthesis and reasoning services.
- **`prompts/`**: Prompt template definitions for IBM Bob decision support.
- **`analyzers/`**: Multi-factor risk analyzers.
- **`recommenders/`**: Operational recommendation engines (Rerouting, Fleet redeployment).
- **`bob/`**: IBM Bob conversational interface wrappers and mock adapters.
- **`mock/`**: Mock input/output payloads for offline testing.
